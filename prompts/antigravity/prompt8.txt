# Build the Placement Intelligence Foundation for LearnPath AI

## Objective

Implement **Phase 1: Placement Intelligence Foundation**, a lightweight, intelligence-driven career readiness layer that integrates seamlessly with the existing LearnPath AI ecosystem.

This phase is **not** a placement portal, hiring platform, or job application system. Its purpose is to provide learners with a centralized **AI Career Readiness Command Center** that evaluates preparedness, identifies skill gaps, recommends next actions, and maps learners toward suitable engineering career paths.

The implementation must prioritize **reuse, consistency, scalability, and token efficiency** by leveraging existing intelligence systems rather than recreating them.

---

# Critical Alignment Requirements

Before generating any code, thoroughly review and align with all existing LearnPath AI systems:

* Dashboard
* Assessments Engine
* Adaptive Roadmap Intelligence Engine
* Courses Intelligence System
* AI Mentor
* Unified Intelligence Sync Engine
* Adaptive Intelligence Layer

The project already includes shared intelligence infrastructure such as:

* Recommendation Engine
* Progression Engine
* Skill Graph Engine
* Adaptive Engine
* Intelligence Selectors
* Learning Store
* Existing Readiness Calculations

### Reuse Existing Systems

The Placement Intelligence Foundation must consume and extend existing outputs.

Do **not**:

* Recreate intelligence logic
* Create duplicate stores
* Build new recommendation engines
* Reimplement adaptive systems
* Duplicate readiness calculations
* Introduce parallel state management

The placement layer should function as a presentation and orchestration layer built on top of existing intelligence outputs.

# Product Purpose

This page is not intended to help users apply for jobs.

Instead, it should act as an intelligent readiness dashboard that answers questions such as:

* Am I placement ready?
* Which engineering roles best fit my profile?
* What skills are currently limiting my readiness?
* What should I learn next?
* Which roadmap milestones matter most?
* How prepared am I for interviews?
* Which engineering career paths align with my intelligence profile?

Every section should contribute toward answering these questions using existing intelligence outputs.
