Backend Phase 1 Foundation – Production-Ready Foundation Layer

Context:

The backend architecture has been fully approved and validated.

Generate ONLY Phase 1 Foundation of the LearnPath backend system.

This phase establishes the core platform infrastructure that all future modules will depend on.

Do NOT generate any Phase 2+ functionality.

Focus on creating a scalable, maintainable, enterprise-grade foundation following Spring Boot best practices and clean architecture principles.

Tech Stack:

* Spring Boot 3.x
* Java 17
* PostgreSQL 18
* Maven
* Docker
* Docker Compose
* Flyway
* Spring Security 6
* JWT Authentication
* Jakarta Validation
* Lombok (optional, minimal usage)

Architecture Requirements:

Use a modular package structure aligned with the approved architecture:

* auth
* user
* security
* config
* common
* exception

Apply:

* Clean Architecture principles
* Layered architecture (Controller → Service → Repository)
* Constructor injection only
* DTO pattern for all API communication
* Separation of domain and transport models
* Centralized exception handling
* Validation-first request processing
* Secure-by-default configuration
* Production-ready configuration structure

Database Design:

Create foundational entities only:

### User

Fields:

* id (UUID)
* email (unique)
* password_hash
* first_name
* last_name
* active
* created_at
* updated_at

### Role

Fields:

* id
* name
* description

### UserProfile

Fields:

* id
* user_id
* avatar_url
* timezone
* preferred_language
* created_at
* updated_at

Relationships:

* User ↔ Role (Many-to-Many)
* User ↔ UserProfile (One-to-One)

Persistence Requirements:

* JPA/Hibernate mappings
* Proper indexes
* Foreign key constraints
* Audit timestamps
* Flyway migration scripts
* Initial role seed data

Authentication API:

### Register

POST /api/auth/register

Requirements:

* Validate email format
* Validate password strength
* Prevent duplicate accounts
* Assign default USER role
* Return authenticated user response

### Login

POST /api/auth/login

Requirements:

* Email/password authentication
* JWT generation
* Secure authentication flow
* Standardized response format

### Current User

GET /api/auth/me

Requirements:

* JWT protected endpoint
* Return authenticated user profile
* Role information included

Security Requirements:

* BCrypt password hashing
* Stateless authentication
* JWT Bearer token support
* Public auth endpoints
* Protected user endpoints
* Role-based authorization foundation
* Security filter chain configuration
* Unauthorized access handling
