## Database

Create Flyway migration:

V14__create_analytics_tables.sql

Create tables:

### analytics_snapshots

* UUID primary key
* user_id (FK)
* overall_progress
* roadmap_completion
* assessment_average
* readiness_score
* total_xp
* mastery_score
* snapshot_time
* created_at
* updated_at

### analytics_activity_logs

* UUID primary key
* user_id (FK)
* activity_type
* activity_reference
* metadata (JSONB)
* created_at

### analytics_learning_streaks

* UUID primary key
* user_id (UNIQUE, FK)
* current_streak
* longest_streak
* last_activity_date
* updated_at

Requirements:

* Add indexes for user_id and frequently queried fields
* Add update triggers where needed
* Ensure referential integrity
* Ensure Flyway migration is idempotent and valid
