Database

V9__create_assessment_metrics.sql

Create table:

assessment_metrics

Columns:

* id UUID PRIMARY KEY
* assessment_result_id UUID UNIQUE NOT NULL (FK)
* user_id UUID NOT NULL
* template_id UUID NOT NULL
* technical_score DECIMAL(5,2)
* aptitude_score DECIMAL(5,2)
* behavioral_score DECIMAL(5,2)
* communication_score DECIMAL(5,2)
* domain_readiness_score DECIMAL(5,2)
* overall_score DECIMAL(5,2)
* computed_at TIMESTAMP NOT NULL

Requirements:

* Add appropriate indexes for performance
* Ensure referential integrity
* Ensure uniqueness of assessment_result_id
* Ensure migration is idempotent and safe

Evaluation Engine

Create:

AssessmentEvaluationService

Responsibilities:

* Validate assessment session completion
* Prevent duplicate evaluations (idempotency required)
* Aggregate answers from assessment_answers
* Compute category-wise scores
* Compute overall score
* Persist assessment_result (if not already finalized)
* Persist assessment_metrics
* Trigger post-evaluation events

Scoring Rules

* Fully deterministic logic only
* Use values from assessment_options
* No randomness, no heuristics, no ML
* No adaptive or recommendation logic
* Ensure consistent scoring across executions
